# TP 3 - Datos externos con useEffect

Proyecto realizado con React, Axios y useEffect para consumir una API pública.

## Variable de entorno

Crear un archivo `.env` en la carpeta principal del proyecto con:

VITE_API_URL=https://jsonplaceholder.typicode.com

## Instalación

Ejecutar:

npm install

## Ejecutar el proyecto

Ejecutar:

npm run dev
